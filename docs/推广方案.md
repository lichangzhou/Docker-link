# 推广方案

> 本文档是 Docker-Link 的**完整推广计划**，包含平台选型、内容矩阵、投放节奏、预算与 KPI 监测。
> 文档定位：看完这一份就能接手推广执行，不只写"最终做什么"，还写"为什么选这个平台"。

---

## 一、项目简介

Docker-Link 是一款 **开源 Docker 可视化管理面板**，对标 Dockter，提供容器、镜像、卷、网络、Compose、文件管理、Web 终端、远程节点 Agent、企业微信告警等完整功能。当前已在 NAS（`192.168.50.50:9080`）上线 `v1.2.3`，Docker Hub 最新镜像为 `v1.3.0`（仅 amd64，已 Cython 加固）。

---

## 二、目标受众 & 核心卖点

| 受众 | 典型需求 | Docker-Link 核心卖点 |
|------|----------|----------------------|
| **企业运维 / IT 管理员** | 多主机集中管理、远程节点、审计、企业微信告警 | 多节点 Agent、统一面板、企业微信通知、细粒度权限 |
| **中小企业自建私有云** | 一键部署、文件管理、图标库、可视化监控 | 单容器一键部署、绿色玻璃 UI、图标管理、任务中心 |
| **个人/家庭实验室（Homelab）** | 轻量、易上手、Docker-Compose 可视化 | 轻量前端、Compose 编辑、Web 终端、无数据库 |
| **开源社区开发者** | 可自定义、源码透明、CI/CD 集成 | 完全开源、Cython 加固版、Git-Hook 更新检查 |
| **DevOps / SRE** | 多云/多节点、镜像更新、监控告警 | 远程 Agent、镜像更新链路（加速源 → docker-sock → 代理）、日志/监控面板 |

## 八、风险与应对

| 风险 | 可能影响 | 应对措施 |
|------|----------|----------|
| **内容同质化**（与 Portainer、Dockge 类似） | 曝光率下降 | 强调 **EvoLink 绿玻璃 UI**、**企业微信告警**、**多节点 Agent** 的独特组合 |
| **平台审核不通过**（云 Marketplace） | 无法进入企业渠道 | 提前准备合规文档、图标、资质，采用 **Docker Hub** 作为备份渠道 |
| **技术更新滞后**（Docker-CE 升级） | 用户迁移成本 ↑ | 建立自动化 **CI/CD** 检测新 Docker 版本兼容性，及时发布补丁 |
| **安全泄露风险**（Docker-sock 只读挂载） | 企业用户顾虑 | 在文档中明确安全模型，提供 **只读** 挂载方案及 **审计日志** |
