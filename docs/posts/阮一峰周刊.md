## Issue 正文（复制到阮一峰周刊）

```
【开源自荐】Docker-Link：单容器部署的 Docker 可视化面板

自用的 Docker 管理面板，MIT 开源。容器/镜像/卷/网络/端口全 CRUD，
Compose 项目直接扫硬盘目录（面板与 yaml 同一份事实来源），文件管理器、
docker exec + PTY 的 Web 终端、多节点（Agent 或纯 SSH 通道）、企业微信告警。

前端是单文件 index.html，零构建；镜像更新检测比对 manifest digest 而非 tag，
拉取做了加速源 → dockerd 直连 → 容器内代理 load 三层兜底。

同作者另有媒体库治理（EvoLink）与跨平台播放器（Playable）两个开源项目，
同一个 GitHub 账号下。

docker run -d --name docker-link --restart always -p 9080:9080 \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  -v /opt/compose:/opt/compose:rw \
  lichangzhou/docker-link:latest

https://github.com/lichangzhou/Docker-link
```

## HelloGitHub 版本（更强调「亮点 + 完整度」）

```
【开源自荐】Docker-Link：单容器部署的 Docker 可视化面板

一个自己写的 Docker 管理面板，MIT 协议，README 完整，含 compose 一键部署文件。

亮点：
- Compose 项目直接读取硬盘上的 yaml，面板与文件不会不一致
- Web 终端基于 docker exec + PTY，真交互式 shell
- 多节点支持 Agent（HTTP + Token）与纯 SSH 双通道
- 镜像更新比对 manifest digest 而非 tag，拉取有三层兜底
- 前端单文件 index.html，无构建步骤，镜像体积小

目前仅提供 linux/amd64 镜像，ARM 需自行构建。

https://github.com/lichangzhou/Docker-link
```
